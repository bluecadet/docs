A reusable docs system — a CLI and a reusable CI workflow that turns a repo's markdown into a
branded static site. No Astro project, no config, no build pipeline to maintain.

## Packages

- **@bluecadet/docs** — CLI that turns a repo's colocated markdown (README + docs/) into a
  branded static site. No install required in the consumer repo. See the
  [CLI reference](reference/cli/).
