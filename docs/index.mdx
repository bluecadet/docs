---
title: bluecadet docs
description: A CLI that turns a repo's colocated markdown into a static docs site — no Astro project, no config, no build pipeline to maintain.
---

`@bluecadet/docs` reads a repo's `README.md` and `docs/` tree and builds a static site from it:
sidebar navigation, full-text search, and a designed landing page, all generated from markdown
you'd already write anyway.

```sh
npx @bluecadet/docs build
```

No install step, no `package.json` in the consumer repo — the CLI bundles its own Astro app and
`node_modules`. Run it from any repo (Go, C#, Node, whatever); it only ever reads markdown.

> [!TIP]
> First time here? [Add docs to your repo](tutorials/add-docs-to-your-repo/) walks through the
> whole setup, including wiring it into CI.
